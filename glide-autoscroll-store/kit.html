1

Finish your account settings

Developer Dashboard, Account tab
  • Registration fee: paid.
  • Make sure 2-Step Verification is on for the Google account you registered with. Publishing and updating need it.
  • Account tab: set a Publisher name (shown as "Offered by" on the listing) and verify a contact email. That email appears in the listing's contact details, so use one you're happy to show.
  • Declare trader or non-trader status (EU rules). A free hobby project is usually non-trader. If it's part of a business you're a trader, and your verified business details are shown publicly. Google leaves the call to each publisher.
2

Try the upload build in Brave

brave://extensions, before you submit
  1. Unzip glide-autoscroll-1.2.1-chrome-web-store.zip into a folder.
  2. In brave://extensions, remove your current Glide copy, then Load unpacked and pick that folder.
  3. Use it as normal for a day: long pages, sites with side panels, embedded videos and posts, the toolbar switch.

The listing says Linux and Mac. Nothing in the code is Mac-specific, but it has only been run on Linux. If you'd rather claim only what's been tried, edit the description in manifest.json and rebuild the zip.

Privacy practices

Privacy tab
Are you using remote code?No, I am not using remote code.
What user data do you plan to collect? Tick none of the data types. Then tick all three certifications:
  • I do not sell or transfer user data to third parties, outside of the approved use cases
  • I do not use or transfer user data for purposes that are unrelated to my item's single purpose
  • I do not use or transfer user data to determine creditworthiness or for lending purposes

Glide reacts to clicks and pointer position, but only in memory while scrolling; nothing is stored or sent, which is why no data type applies. Similar autoscroll extensions declare the same. If a reviewer disagrees, tick "User activity" and give that explanation.

9

Submit for review

Submit for review, top right
  • Most reviews finish within a few days but some take a few weeks. Access to all sites, a new account and a new extension each add scrutiny, so expect the slower end. You'll get an email either way.
  • To choose the launch moment yourself, untick publishing automatically. You then have 30 days after approval to publish.
10

Once it's live

Brave, and the project folder for updates
  • Install Glide from the store, then remove the unpacked copy so only one copy handles middle-clicks.
  • Replace "coming soon" with the store link in README.md and in the release notes (Edit release on GitHub).
  • To ship an update: change the code, raise version in manifest.json, run npm test and npm run store:zip in glide-autoscroll-tests, then Package tab, Upload new package, Submit.
  • If the look changes, run npm run store:images so the screenshots match the extension.
