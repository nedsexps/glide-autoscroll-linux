# Changelog

## 1.2.1 — first public release

Middle-click autoscroll for Chrome, Brave and other Chromium browsers on Linux and Mac.

- Scrolls whatever is under the pointer, including inner panels, carousels, shadow DOM and embedded frames
- Click to toggle, hold and drag, or both; speed, acceleration and dead zone settings with a test area
- Per-site switch in the toolbar popup
- Never triggers Linux middle-click paste; links and text boxes keep their normal middle-click
- Correct speed at fractional display scaling and any page zoom; stops promptly back at the start point
- Works in tabs that were already open when it's installed, updated or switched back on
- No network requests, no data collected
